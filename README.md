# 台股策略實驗室

單一使用者的虛擬台股帳戶。保留原 Cloudflare Worker + KV 架構，純 HTML/JS、無前端套件。只記錄模擬交易，不連接券商、不送出真實訂單。

## 開始使用

- **本機完整功能**：Node.js 22 以上，執行 `npm start`，開啟 http://127.0.0.1:8787 。行情與回測透過本機伺服器轉送公開資料；預設不啟用雲端帳戶 API。
- **只用手動帳戶**：直接開啟 `public/index.html`，可手動填價格下單、記錄策略、匯出備份。行情視瀏覽器跨來源限制而定，回測需設定 Worker 網址。
- **測試**：`npm test`，不需要安裝套件；測試使用獨立記憶體與公開行情樣本，不污染正式帳戶。
- 預設虛擬本金新臺幣 100 萬，可在帳戶設定重置。先寫下策略規則，再填交易理由並買進／賣出。需追蹤自己的策略；程式本身不會證明任何策略保證獲利。

## 2026-10-31 修正版

- 均線交叉及停損停利：收盤產生訊號、下一交易日開盤成交，消除原先當日收盤判斷又當日收盤成交的偏差。最後一天訊號不執行。停損不是盤中保證價格。
- 滑價可設 0–100 基點，買入加價、賣出減價，預設 10 基點；模擬開盤價可有小數，未依股票升降單位撮合。
- 定期定額定義為「期初本金已備妥、每月分批投入」，沒有額外外部入金；基準也使用同筆期初本金。不是每月薪資新增現金流模型。
- 買進持有基準也計買入手續費及滑價，修正最低手續費造成負現金。期末持股按收盤市值計價，未強制平倉、不扣未發生賣出成本。
- 帳戶加入策略規則、逐筆交易理由；保留初始資產紀錄。勝率按賣出筆數計算，部分賣出不視為完整回合。
- 股數必須為正整數；禁止無效代號及非有限數值；持股類型不能藉由賣出選項改稅率。
- 報價區分最近成交價、最佳買價（非成交）、昨收；附日期、時間。這不是即時撮合引擎。
- 雲端改手動同步，避免自動覆蓋；下載、匯入、重置前保留本機復原備份。密碼只留目前分頁，舊版儲存在 localStorage 的密碼會移除。
- 匯入及 Worker 上傳驗證帳戶結構；無效檔案不覆蓋帳戶。多裝置仍需避免同時編輯，KV 不提供原子版本衝突控制。
- 歷史資料缺月時停止回測；日線開盤相對前收盤跳動超過 25% 時停止，要求先取得還原資料。這是保守偵測，並不能辨識所有公司行動。

## 模型限制

只支援一般股票與股票型 ETF。股票賣出稅 0.3%、股票型 ETF 賣出稅 0.1%；沒有債券 ETF 免稅、當沖減稅等機制。手續費模型為 0.1425% × 折扣、最低 20 元，整元無條件捨去；此為可重現的簡化模型，實際券商／零股方案可能不同。

資料是未還原日線，**未計配息、除權息、分割及減資**；不應用來聲稱含息長期策略有效。未模擬流動性、漲跌停無法成交、零股不同成交價或 T+2 交割。手動交易可填任意時間與價格。績效曲線回撤僅反映已記錄的估值點。若策略期間含公司行動，需先補還原資料與現金流模型。

- https://accessibility.twse.com.tw/zh/about/company/guide.html
- https://www.twse.com.tw/zh/products/securities/etf/overview/rules.html

## Cloudflare 部署

原 `wrangler.toml` 的 Worker 名稱 `escape` 與 KV namespace 綁定保持不變；部署前確認該 KV 屬於你的 Cloudflare 帳戶。

1. 新環境先以 `npx wrangler kv namespace create tw-paper` 建立 KV，將 id 填入設定；已有 namespace 不必重建。
2. 執行 `npx wrangler deploy`。
3. 執行 `npx wrangler secret put TOKEN`，自行輸入同步密碼。沒有 TOKEN 仍可查價、回測和使用瀏覽器本機帳戶。
4. 打開部署網址，手動輸入同步密碼並選擇上傳或下載。開網頁不會自動取代本機資料。

此版本已完成本機測試與真實資料驗證；Cloudflare 正式部署仍需另行執行並驗證。

## 結構與 API

- `public/index.html`：網頁及互動。
- `public/core.js`：前後端共用驗證與回測計算。
- `worker/src/index.js`：`GET /quote?codes=2330,6488`、`GET /history?code=2330&months=6`、`GET/PUT /account`。
- `dev-server.mjs`：只綁定 127.0.0.1 的本機預覽。可透過環境變數 TOKEN 啟用測試同步；帳戶寫到忽略版控的 `.local-account.json`，歷史快取在記憶體。
- `tests/accounting.test.js`：獨立計算、介面邏輯與 API 測試。

本機帳戶 key 為 `tw-paper-account-v1`；覆蓋前備份為 `tw-paper-account-v1-before-restore`；讀入異常原始資料保留於 `tw-paper-account-v1-invalid`。JSON 匯出不含同步密碼。
